# 📌 Project Overview

This project is a professional Power BI dashboard designed to analyze automobile sales across multiple brands. It provides interactive insights using KPIs, dynamic navigation, filters, buttons, and brand-specific dashboards.

The dashboard enables users to:

- Analyze sales performance
- Compare different automobile brands
- Explore model-wise insights
- Monitor yearly sales trends
- Navigate through dedicated brand pages
